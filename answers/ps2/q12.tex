\emph{Solution:} Let $x\in\bar{A}$. Now,
\begin{align*}
  x\in\bar{A} &\iff \text{every neighbourhood of } x \text{ intersects } A\\
              &\iff x\in A \text{ or } x\in A'\\
              &\iff x\in A\cup A'.
\end{align*}
Since $x$ was chosen arbitrarily, we can say $\bar{A}=A\cup A'$.

For the second part, assume $A$ is closed. Then
$\bar{A}=A\implies A\cup A'=A\implies A'\subseteq A$. On the other hand, if we assume
$A'\subseteq A$, then we get $\bar{A}=A\cup A'=A$. Thus, in this case, we can conclude that $A$
is closed. As both directions of the double implication hold, we have $A$ is closed in $X$ if
and only if $A'\subseteq A$. \hfill$\square$
